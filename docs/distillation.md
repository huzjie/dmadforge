# 蒸馏原理与损失函数

## 为什么逐点 MSE 不够

- 模式塌缩：MSE 逼学生输出多模态老师的"平均"，而平均图是模糊的。
- 步网格错位：50 步和 4 步时间轴对不齐。

## 分布匹配

目标从 `min ||student-teacher||²` 换成 `min D(P, Q)`。

- **MMD**：`MMD² = E[k(x,x')] + E[k(y,y')] - 2E[k(x,y)]`，RBF 核。积分概率度量，免密度估计。
- **Wasserstein-1**：传输代价，对模式塌缩更稳健。
- **对抗散度**：判别器误差 ≈ JS 散度下界。

## 收敛信号

判别器准确率 `1.0 → 0.5` 是收敛的黄金信号：学生分布已贴到老师分布，判别器只能瞎猜。
